# FLAtlas V2

FLAtlas V2 is a Windows desktop tool for Freelancer modding.

## Download

Get the latest Windows build from the GitHub Releases page:

[Download FLAtlas V2](https://github.com/flathack/FLAtlas-V2/releases/latest)

For older versions, checksums, and release notes, see:

[All releases](https://github.com/flathack/FLAtlas-V2/releases)

## What FLAtlas Helps With

- Browse and edit Freelancer systems, bases, universe data, INI files, IDS entries, infocards, trade routes, NPC data, and mod resources.
- Work with interactive 2D and 3D previews for systems, objects, zones, bases, docking rings, tradelanes, and connections.
- Use practical tools for modding workflows such as patching, path finding, screenshots, updates, and launch helpers.

## Requirements

- Windows
- A Freelancer installation or mod installation to work with
